# 첫 인터랙티브 웹 실습

마우스 움직임에 반응하는 웹 페이지를 만드는 실습 공간입니다.
전체 화면을 채우는 어둡고 신비로운 숲을 구현했습니다.

## 이번 단계의 동작
- 처음에는 숲이 어둡게 보입니다.
- 마우스를 움직이면 약 1.8초에 걸쳐 부드럽게 밝아집니다.
- 마지막 움직임으로부터 2초가 지나면 약 1.8초에 걸쳐 다시 어두워집니다.
- 지나간 자리의 작은 흰빛은 약 4.2초 동안 천천히 사라집니다.

## 준비된 것
- 프로젝트 전용 카파시 지침 스킬과 루트의 `AGENTS.md` 작업 규칙
- 이 실습 폴더만 제공하는 로컬 서버 실행 파일 `start.cmd`
- Python 3.14.6, Node.js v26.13.0, npm 11.20.0 설치 확인
- Chrome과 Edge 설치 확인
- 추가 패키지 설치가 필요 없는 HTML·CSS·JavaScript 방식

확인 날짜: 2026-11-10. 첫 실행에 쓰는 8000번 포트는 준비 시점에 비어 있었습니다.

## 실습 파일
| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면에 들어갈 글과 요소 |
| `style.css` | 색상, 크기, 배치 |
| `script.js` | 마우스 움직임에 따른 반응 |
| `forest.svg` | 외부 다운로드 없이 표시되는 숲 일러스트 |

기존 폴더의 HTML 파일은 그대로 보존했습니다. 인터넷 연결이나 추가 설치 없이 실행할 수 있습니다.

## 실행 방법
1. 이 폴더의 `start.cmd`를 두 번 클릭하고 실행 창을 열어 둡니다.
2. Chrome 또는 Edge에서 <http://127.0.0.1:8000/>을 엽니다.
3. 종료할 때 실행 창에서 `Ctrl+C`를 누릅니다. 종료 확인이 나오면 `Y`를 누릅니다.

브라우저 영역을 가득 채워 표시됩니다. Chrome·Edge에서 브라우저 테두리까지 숨기려면 `F11`을 누르세요.
서버는 내 컴퓨터에서만 접속하도록 설정되어 있습니다. 매번 실행 파일을 한 번만 실행하면 됩니다.
