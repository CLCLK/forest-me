# 숲 속의 나 v2 실습

마우스를 움직이면 숲이 밝아지고 요정이 따라옵니다. 2초 동안 멈추면 숲이 부드럽게 어두워집니다.

## 이번 변경
- `숲에서 나가기` 또는 브라우저 뒤로 가기로 시작 화면에 돌아옵니다. 설정은 유지됩니다.
- 두 화면의 BGM 버튼으로 48초 오리지널 음악을 켜고 끕니다. 화면을 오가도 재생이 이어집니다.
- 반짝임과 까마귀 효과를 더 풍성하게 만들고 낙엽에는 회색 다섯 가지를 섞었습니다.
- 요정이 움직이면 배경이 앞으로 흐르고, 멈추면 서서히 잦아듭니다.
- 파일을 열면 `숲속의 나` 시작 화면이 먼저 표시됩니다. 웹캠·숲·불빛·확대 설정 후 `숲으로 들어가기`를 누르면 선택한 설정이 그대로 이어집니다.
- 캐릭터가 왼쪽으로 이동하면 이미지와 합성 얼굴이 함께 좌우반전됩니다. 오른쪽 이동은 원래 모습입니다.
- 캐릭터 크기를 이전의 80%로 줄였습니다.
- 의상·날개·머리띠를 유지하고 부드러운 동화 삽화풍으로 바꿨습니다.
- 숲 선택: 어두운 숲 / 거미줄의 숲 / 공동묘지 숲
- 불빛 선택: 반짝임 / 새끼 까마귀 / 낙엽
- 파일 첨부 기능은 제거했습니다.
- 웹캠 얼굴 합성, 타원형 미리보기와 0.8~3배 확대 기능은 유지합니다.

## 실행
폴더 상위의 `숲속의나v2_실습.html`을 두 번 클릭하면 됩니다. 배경 3장과 캐릭터 이미지, 음악과 코드가 한 파일에 들어 있습니다.
로컬 미리보기는 상위 폴더의 `숲속의나_실행.cmd`를 두 번 클릭하면 열립니다. 실행 창을 닫거나 채팅이 끝나도 서버가 유지됩니다. 이미 실행 중이면 같은 서버를 재사용합니다.
종료할 때는 `숲속의나_서버끄기.cmd`를 두 번 클릭하세요. PC를 재시작한 뒤에는 실행 파일을 다시 눌러주세요.
주소는 http://127.0.0.1:8000/ 입니다. 이 폴더의 `start.cmd`도 같은 방식으로 실행합니다.
웹캠은 브라우저의 카메라 권한이 필요합니다. 자동 얼굴 맞춤은 인터넷에서 모델을 불러오며, 모델을 불러오지 못해도 중앙 얼굴 영상과 확대 조절로 합성할 수 있습니다.

## 이미지
내장 image_gen 도구로 만든 이미지입니다. 생성·편집 프롬프트는 `art-prompts-v2.json`에 기록했습니다.
- `fairy-storybook-clean.png`: 동화풍 요정, 투명 배경
- `forest-moonlit.png`: 기존 달빛 숲
- `forest-webs.png`: 거미줄 숲
- `forest-graveyard.png`: 묘지 숲

## 확인
세 가지 배경 선택, 세 가지 효과의 그리기, 효과 전환 시 이전 입자 정리, 입자 수 제한과 2초 정지 동작을 검사했습니다.
