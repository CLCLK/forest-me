# 숲속의나

마우스 움직임과 웹캠에 반응하는 인터랙티브 숲 실습 프로젝트입니다.

## 공유 링크로 실행

<https://clclk.github.io/forest-me/>

별도 설치 없이 Chrome 또는 Edge에서 열 수 있습니다. 웹캠 기능을 쓰려면 카메라 사용을 허용해 주세요.
`main` 브랜치의 변경 사항은 GitHub Pages에 자동으로 배포됩니다.

## 실행 방법

1. Python이 설치된 Windows에서 `숲속의나_실행.cmd`를 두 번 클릭합니다.
2. Chrome 또는 Edge에서 <http://127.0.0.1:8000/>을 엽니다.
3. 마우스를 움직이거나 화면의 ‘웹캠 켜기’를 눌러 사용합니다.
4. 종료할 때 `숲속의나_서버끄기.cmd`를 두 번 클릭합니다. 실행 창이나 채팅을 닫아도 서버는 유지됩니다.

웹캠 기능에는 브라우저의 카메라 사용 허용이 필요합니다.

## 파일 구성

- `practice-01/`: 현재 실습 화면, 스크립트와 이미지
- 루트의 HTML 파일: 이전 실습과 손동작 인터랙션 버전
- `timburton1.jpg`, `timburton2.jpg`: 프로젝트 참고 이미지
- `AGENTS.md`, `.agents/`: 프로젝트 작업 규칙과 지침
